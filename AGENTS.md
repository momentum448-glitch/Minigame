# AI / Agent Continuation Rules

Before doing any work in this repository:

1. Read `PROJECT_START_HERE.md`.
2. Follow its reading order.
3. Treat `PROJECT_STATE.md` as the current semantic handoff.
4. Treat `docs/DECISIONS.md` as durable decisions already approved by the user.
5. Check `docs/AUTO_TECH_STATUS.md` and GitHub Actions when current deployment status matters.
6. Do not ask the user to repeat decisions already recorded as CHỐT.
7. After meaningful gameplay, architecture, UX, or deployment work, update the handoff files before declaring the milestone complete.

The current task is always the **NEXT ACTION** in `PROJECT_STATE.md`, unless the user explicitly changes priority.
